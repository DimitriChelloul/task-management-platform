CI / CD & PDF generation (GitHub Actions)

This file shows an example GitHub Actions workflow that builds the project, runs tests and generates the course PDF using Pandoc and Chrome headless. The workflow will store the generated PDF as an artifact.

Create `.github/workflows/course-pdf.yml` with the following content:

```yaml
name: Build Course PDF
on:
  push:
    paths:
      - 'docs/**'
      - '.github/**'

jobs:
  build_pdf:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up JDK 21
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '21'
      - name: Install pandoc and chrome
        run: |
          sudo apt-get update
          sudo apt-get install -y pandoc
          wget -q -O - https://dl-ssl.google.com/linux/linux_signing_key.pub | sudo apt-key add -
          sudo sh -c 'echo "deb [arch=amd64] http://dl.google.com/linux/chrome/deb/ stable main" > /etc/apt/sources.list.d/google-chrome.list'
          sudo apt-get update
          sudo apt-get install -y google-chrome-stable
      - name: Generate HTML
        run: |
          pandoc docs/course-handbook.md -s -o docs/course-handbook.html
      - name: Generate PDF with headless Chrome
        run: |
          ABS=$(realpath docs/course-handbook.html)
          google-chrome --headless --disable-gpu --print-to-pdf=docs/course-handbook.pdf "file:///$ABS"
      - name: Upload PDF artifact
        uses: actions/upload-artifact@v4
        with:
          name: course-handbook-pdf
          path: docs/course-handbook.pdf
```

Notes:
- This workflow uses Chrome headless to print HTML generated by Pandoc. You can change to LaTeX if you install TeX in the runner.
- The artifact can be downloaded from the Actions run page.
